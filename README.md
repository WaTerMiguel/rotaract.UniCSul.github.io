# 🤝 Rotaract Club Diadema Floreat — Website Institucional

Este repositório contém o código-fonte do website desenvolvido para o **Rotaract Club Diadema Floreat**, uma organização focada no desenvolvimento de lideranças jovens e ações sociais, comunitárias e ambientais na cidade de Diadema - SP.

> 🎓 **Projeto Acadêmico:** Este site foi construído para fins educacionais, aplicando boas práticas de desenvolvimento web com HTML5 semântico, acessibilidade e estruturação de dados.

---

## 📌 Sobre o Projeto

O objetivo da plataforma é divulgar a missão do clube, apresentar suas principais iniciativas sociais e disponibilizar um canal de recrutamento para novos voluntários e apoiadores da região.

---

## 📄 Estrutura das Páginas

O site é composto por **3 páginas HTML** estruturadas de forma semântica:

1. **`index.html` (Início):**
   * Apresentação da ONG e seus pilares institucionais (Missão, Visão e Valores).
   * Destaque para áreas de atuação (Ações comunitárias, Proteção animal e Juventude).
   * Informações de localização e redes sociais.

2. **`pages/projeto.html` (Projetos Sociais):**
   * Detalhamento das principais iniciativas do clube, incluindo:
     * **Nataau Animal:** Campanha de nutrição e doação para animais resgatados.
     * **Páscoa que Transforma:** Atividades lúdicas e doações para casas de acolhimento infantil.
     * **Ação Floreat nas Ruas:** Distribuição de kits de higiene para pessoas em situação de vulnerabilidade.
     * **Meu Primeiro Big Mac:** Parceria social vinculada ao McDia Feliz.
     * **Oficina dos Sabonetes:** Capacitação e produção artesanal na APAE Diadema.
     * **Floreat Fest:** Evento beneficente para arrecadação de fundos.

3. **`pages/cadastro.html` (Seja um Voluntário):**
   * Formulário completo para novos voluntários.
   * Coleta de dados pessoais, endereço e áreas de interesse (Voluntariado, Sustentabilidade, Causa Animal e Cidadania).
